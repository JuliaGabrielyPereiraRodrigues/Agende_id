# AgendeID — Sistema de Agendamento com Chatbot

O **AgendeID** é um projeto acadêmico de desenvolvimento web que propõe um sistema de agendamento de serviços para emissão da Carteira de Identidade, com atendimento automatizado por meio de um chatbot integrado à Inteligência Artificial.

A aplicação busca facilitar o acesso às informações, automatizar o atendimento e otimizar o gerenciamento de agendamentos.

## 🚀 Tecnologias utilizadas

### Back-end
- Python
- Flask
- SQLite

### Front-end
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Fetch API

### Inteligência Artificial e Processamento de Linguagem Natural
- TensorFlow
- NumPy
- NLTK

## ✨ Funcionalidades

- Atendimento automatizado por chatbot.
- Agendamento de serviços por meio de conversação.
- Cadastro e autenticação de usuários.
- Consulta, alteração e cancelamento de agendamentos.
- Visualização e gerenciamento da agenda.
- Confirmação de presença.
- Geração de relatórios de atendimentos.
- Processamento de linguagem natural para interpretação das mensagens dos usuários.
- Classificação de intenções utilizando modelo de rede neural.

## 🧠 Inteligência Artificial

O chatbot utiliza técnicas de Processamento de Linguagem Natural (PLN) para interpretar as mensagens enviadas pelos usuários e identificar suas intenções.

São utilizadas as bibliotecas:
- **NLTK:** processamento e análise de linguagem natural.
- **NumPy:** processamento e manipulação de dados numéricos.
- **TensorFlow:** execução do modelo de rede neural responsável pela classificação de intenções.

## 🏗️ Arquitetura

O sistema utiliza Python com Flask no back-end, seguindo uma organização baseada no padrão MTV (Model-Template-View).

O front-end é desenvolvido com HTML, CSS e JavaScript, utilizando Fetch API para comunicação assíncrona com o servidor.

O armazenamento das informações é realizado por meio do banco de dados SQLite.

## 🎯 Objetivo do projeto

Desenvolver uma solução de atendimento digital que integre desenvolvimento web e Inteligência Artificial, proporcionando uma experiência mais acessível e organizada para o processo de agendamento de serviços.

## 📚 Natureza do projeto

Projeto acadêmico desenvolvido no contexto universitário, envolvendo conceitos de desenvolvimento web, banco de dados, arquitetura de software e Inteligência Artificial.
